# CAMARA compliance

This project is designed to expose network capabilities via the CAMARA API standard.

## Supported CAMARA APIs

- **Quality on Demand (QoD)**: This project implements functionality allowing for QoS modifications which aligns with the CAMARA Quality on Demand API availability. The northbound `/qos` endpoint serves as the entry point for these requests.
